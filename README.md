# Basic Login & Signup Project

This is a simple full-stack project that demonstrates a **login and signup system** with real-time user authentication. Users can register, log in, and get redirected to the home page if logged in.  

The project includes both **frontend and backend**, with user authentication performed using sessions and MongoDB.

---

## 🚀 Features

- User signup with hashed passwords  
- User login with session authentication  
- Redirects users to the home page if already logged in  
- Logout functionality  
- Real-time check if user is logged in  

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Authentication:** express-session, bcryptjs  
- **Development:** nodemon
